## Edge cases (1)

### EC-1 — A live pause that outlasts the time-shift buffer
- **Trigger:** live content; the viewer pauses inside a pause window for longer than the time-shift buffer, so the suspended position is no longer available on resume.
- **Why it matters:** PLY-59 (L1223-1226) says a mechanism that cannot restore the position is not a pause, and the spec resumes at the oldest available media (§8.8 L3595-3600), then leaves open whether that is still a pause (§8.8 L3600-3601, §8.13 item 4). A Player cannot satisfy PLY-59's MUST here whatever it does.
- **Responsible actor:** Player. `context/` is silent on buffer expiry: R37.2 addresses mechanism, R25.1 only a Player-chosen jump to the live edge. The base answers where playback resumes (§5.16.4, Table 62 NOTE 1: *"If RT is in the past, the playback shall start from the oldest available media segment (the edge of the timeshift buffer)."*), not whether R37.2 holds.
- **Routing:** 5.c (D-3).

## Ambiguities (16)

### A-1 — What the cap on a pause window bounds
- **Context passage:** 03:399-400 R4.2 *"Where the cap bounds cumulative duration — the non-linear families, and linear insertion"*, against the R4 prose 03:380-384 (*"A **pause** slot has no declared duration for a cap to bound"*) and R31.2 03:497-501 (*"on a pause slot it bounds neither, because there is no authored duration for it to bound"*).
- **Readings:** (a) "the non-linear families" includes pause, so the pause cap bounds a cumulative duration; (b) the pause cap is declared and bounds nothing.
- **Spec assumed:** (a), refined to "one pass through a document's candidates": L1000, PLY-24 L1002-1003, L1047-1049, L2150, §8.13 item 9 L3681-3683, Annex E L4726. That makes a Player trim a pause ad mid-pass, which is a bound in the pause family — row R31.2 `contradicted`.
- **Resolution:** R31.2 and ADR 0015 §"What this does NOT change: the pause family" (L74-80): *"A cap on a pause slot is declared like any other and bounds nothing … Making the cap bound something in the pause family was considered … It was rejected: it would reopen R31"*.
- **Tighter sentence:** R4.2 "the overlay family, and linear insertion" (K-1).
- **Routing:** 5.a (T1) for the spec; 5.d (K-1) for R4.2.

### A-2 — PLY-41 held open as a possible departure although R20.1 answers it

- **Spec assumed:** neither; §8.13 item 12 (L3698-3704) leaves it open.
- **Resolution:** R20.1 picks (b); DASH §5.16.2.2.6 lists *"Alternative MPD is a List MPD, and merge process resulted in no available media."*
- **Tighter sentence:** none needed; `context/` already says it.
- **Routing:** 5.a (T3).

### A-3 — Whether drop-before-play on a List MPD is a departure from the base
- **Context passage:** 03:772-774 R7.3 (*"The Player MAY drop a candidate before playback ("drop before play") when its declared duration would push the cumulative slot duration past the cap"*) and R1.5 03:165-172.

- **Spec assumed:** neither; L1075-1077 and §8.13 item 12 leave it open. With A-2 this is why row R1.5 is `partial`.
- **Tighter sentence:** an R40.8-style note on R7.3 (F-2).
- **Routing:** 5.b (F-2).
