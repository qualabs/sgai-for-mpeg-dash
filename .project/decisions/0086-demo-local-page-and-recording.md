# ADR 0086: The demo is a local page and a recording of one session

## Context

`PROJECT.md` asks for a prototype with linear and non-linear ads in the same session.

## Decision

A page served locally plays, with the reference, one session with linear, overlay and pause (taken from a UC vector), and Playwright records it. The audience is assumed to be the DASH WG; the project lead is asked when the demo exists. Publishing it outside is not part of this phase.

## Consequences

- Approved by the project lead on 2026-11-23, audience not answered.
